DCA

Computer Fundamentals

📘 Detailed Notes

Computer क्या है? Computer एक electronic device है जो input लेकर उसे process करता है और useful output देता है।

मुख्य चरण Input → Processing → Output → Storage हैं। Keyboard और mouse input devices हैं, जबकि monitor और printer output devices हैं।

Hardware computer के physical parts हैं; software instructions/programs का समूह है। Hardware को software के बिना उपयोगी कार्य कराने के लिए software चाहिए।

CPU को सामान्यतः computer का brain कहा जाता है। इसके प्रमुख भाग ALU, Control Unit और registers हैं।

RAM temporary working memory है। Power बंद होने पर RAM में रखा सामान्य data सुरक्षित नहीं रहता।

ROM में स्थायी/firmware प्रकार की instructions रखी जा सकती हैं और यह सामान्यतः non-volatile memory है।

Storage में HDD, SSD, pen drive और memory card जैसे माध्यम शामिल होते हैं। SSD में moving mechanical parts नहीं होते।

Operating system hardware और applications के बीच interface उपलब्ध कराता है। Windows, Linux और Android इसके उदाहरण हैं।

File और folder का सही management data को ढूँढने, backup लेने और व्यवस्थित रखने में मदद करता है।

Computer security में strong passwords, updates, backups और suspicious files/links से सावधानी महत्वपूर्ण है।

Windows & File Management

📘 Detailed Notes

Windows में desktop, taskbar, Start menu और File Explorer रोजमर्रा के मुख्य components हैं।

File का नाम और extension उसके प्रकार की पहचान में मदद करते हैं; जैसे .txt, .docx, .xlsx और .pptx।

Folder का उपयोग related files को एक जगह व्यवस्थित रखने के लिए किया जाता है।

Copy और Move अलग हैं: copy में original file रहती है, जबकि move में file नई location पर चली जाती है।

Recycle Bin से सामान्यतः deleted files को restore किया जा सकता है, जब तक उसे permanently remove न किया गया हो।

Keyboard shortcuts काम को तेज कर सकते हैं: Ctrl+C copy, Ctrl+V paste, Ctrl+X cut, Ctrl+Z undo और Ctrl+S save।

File extensions को समझना गलत program में file खोलने की समस्या को कम करता है।

Backup के लिए external drive या trusted cloud storage का उपयोग किया जा सकता है।

Unknown executable files को बिना जाँच चलाना सुरक्षित practice नहीं है।

Regular updates security vulnerabilities को कम करने में मदद करते हैं।

Networking Basics

📘 Detailed Notes

Network दो या अधिक devices को communication/resource sharing के लिए जोड़ता है।

LAN सामान्यतः छोटे/local area में उपयोग होता है, जबकि WAN बड़े geographical area को cover कर सकता है।

IP address network पर device/interface की logical पहचान के लिए उपयोग होता है।

Router अलग networks के बीच packets forward करता है।

Switch local network में devices को connect करके frames forward करता है।

Wi-Fi wireless networking technology है।

Bandwidth और latency अलग concepts हैं; bandwidth capacity से और latency delay से संबंधित है।

DNS domain name को IP address से resolve करने में मदद करता है।

Network security में firewall, encryption और access control महत्वपूर्ण हैं।

Troubleshooting में cable/Wi-Fi, IP configuration, DNS और connectivity को क्रम से check किया जा सकता है।

Cyber Security

📘 Detailed Notes

Cyber security systems, networks और data को unauthorized access और attacks से बचाने का अभ्यास है।

Malware में virus, worm, trojan और ransomware जैसे categories शामिल हो सकती हैं।

Phishing अक्सर social engineering का उदाहरण है।

Strong password लंबा और unique होना चाहिए; passwords reuse करने से risk बढ़ता है।

MFA में password के अतिरिक्त एक या अधिक verification factors हो सकते हैं।

Regular backup ransomware या accidental deletion की स्थिति में recovery में मदद करता है।

Software updates security fixes ला सकते हैं।

Unknown links, attachments और urgent payment requests को verify करना चाहिए।

Least privilege principle में user को केवल आवश्यक permissions दी जाती हैं।

Personal data को अनावश्यक रूप से public करना privacy risk बढ़ा सकता है।
